# Settings Editor

A tabbed desktop preferences window with save/reset/defaults and JSON persistence.

## Modules

- `QtCore`
- `QtGui`
- `QtWidgets`

## Run

```sh
php -dextension=$PWD/build/ext/.libs/qt.so examples/settings-editor/run.php
```

## Data

- persisted settings: `examples/settings-editor/data/settings.json`
