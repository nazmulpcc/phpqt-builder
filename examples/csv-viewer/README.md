# CSV Viewer

A practical CSV utility with search, pagination, and export of the filtered result set.

## Modules

- `QtCore`
- `QtGui`
- `QtWidgets`

## Run

```sh
php -dextension=$PWD/build/ext/.libs/qt.so examples/csv-viewer/run.php
```

## Data

- bundled CSV: `examples/csv-viewer/data/sample-sales.csv`
- filtered exports: `examples/csv-viewer/exports/`
